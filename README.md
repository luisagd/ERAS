# Luisagd — eras

Simple personal site.

How to push from your machine:
1. cd /home/luisagd/eras
2. git init
3. git config user.name "Your Name"
4. git config user.email "you@example.com"
5. git add .
6. git commit -m "Initial site"
7. git branch -M main
8. git remote add origin git@github.com:USERNAME/REPO.git
9. git push -u origin main

Replace USERNAME/REPO with your GitHub repo URL.
